Privacy Policy

Last updated: 25 October 2026

Who we are

Edge is a personal productivity app made and used by one person (github.com/atomi7e). It is not published, sold or offered to anyone else.

Google data Edge accesses

With the user's permission, Edge uses the Google Calendar API with two scopes:

  • calendar.events: to read the user's events and to create, change and delete the events the user edits in Edge.
  • calendar.calendarlist.readonly: to read the list of the user's calendars (names and colours).

How the data is used

Only to show the user's calendar inside Edge and to keep it in sync with Google Calendar. The data is not used for any other purpose.

Where the data is stored

On the user's own computer. Edge has no servers on the internet, no analytics and no advertising. Encrypted backups of that computer's data may be kept in the user's own cloud storage.

Sharing

Edge does not sell, rent or share Google user data with anyone, does not use it for advertising, and does not use it to develop, improve or train AI or machine learning models.

Limited Use

Edge's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time on the Google Account connections page. Deleting Edge's data folder on the computer removes all calendar data Edge has stored.

Contact
